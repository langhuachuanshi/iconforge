## 一、它是什么

一个**纯提示词的 Agent Skill**：整个仓库核心就一个 `SKILL.md` 指令文档，无脚本、无模型调用代码、无依赖。作用是"教"AI Agent 生成商用级 IP 吉祥物图标，配合 Agent 自带的上层生图模型（GPT Image 2、Seedance 5.0 Pro、Nano Banana Pro 等）使用。

安装方式（供团队在 Codex/豆包/Coze 等工具里直接用）：

```bash
npx skills@latest add s1dashu/ip-as-logo-skill
```

## 二、核心设计规则（它的全部"功能"）

| 维度 | 规则 |
|------|------|
| 造型 | 极简，4–7 个大基本形状构成主体轮廓，圆角厚实、无尖锐细节、婴儿感萌系 |
| 配色 | 严格三色语义：两个 IP 主体色 + 一个具名纯色背景色；默认不出双色 |
| 构图 | IP 从左下或右下探出，占画面 85–95%，默认批次三张左下、三张右下 |
| 流程 | 先给 3 个设计方向 → 用户确认后批量生成 6 张独立候选（A1/A2/B1/B2/C1/C2），每张单独全分辨率方形图 |
| 提示词技巧 | 对生图模型绝口不提 logo / 图标 / brand mark，只描述"方形角色图"，避免模型往图标资产方向联想；不指定渐变/阴影公式 |
| 交付原则 | 一次生成全部交付，不自动筛选、不自动重试、不检查透明度 |

## 三、与 IconForge 的对接分析

它不是软件、没有 API、没有可调用的库，**不能作为组件直接对接**。可行的"对接"形态是把它的提示词工程规则移植成 IconForge 的功能。落地点（按性价比排序）：

1. **新增「IP 吉祥物」风格模板**（成本最低）。在现有 14 个风格模板基础上加第 15 个，编译其核心规则：三色语义、左下/右下构图、占比 85–95%、圆角极简，以及"提示词里不出现 logo/图标字样"这条规则（对通义万相/豆包同样适用，能减少模型生成"图标线框"的倾向）。
2. **引导式模式加「吉祥物工作流」**：3 方向提案 → 用户选方向 → 批量生成 6 张（3 左下 + 3 右下）。引导式点选 + 批量生成能力已具备，缺这套提案-确认的交互编排。
3. **不建议照搬**：它的"不筛选、不重试、全量交付"是给对话式 Agent 设计的；IconForge 用户后续本来就会进编辑页处理，保留现有编辑流程即可。它的候选模型名单与我们接的三家无关。

零成本组合用法：用支持 Agent Skills 的工具装上该技能生成候选图，再拖进 IconForge 抠图/编辑/导出。
