# 服务商配置体验修复：对齐 / 测试连接 / 错误透传

- 背景：用户反馈 ①配置卡"已配置"标签错位 ②缺测试连接 ③生成失败只提示"请检查网络或服务商配置"，看不到真实原因
- 调查结论：
  - ① `SettingsView` 的 `.row-top` 用了 `justify-content: space-between`，标签被推到行尾
  - ③ 后端错误本就含 HTTP 状态码+响应体（providers/mod.rs），但 `GenerateView.handleGenerate` 每张失败只 `console.error`，全失败时抛写死文案 `全部生成失败，请检查网络或服务商配置`——真实错误被吞
  - 用户当前配置：阿里云 MaaS 专属端点 + qwen-image-2.0-pro，Key 已存；形式无异常，真实失败原因需由 API 响应体揭晓（依赖 ③ 的透传）
- 凭据红线：检查/展示配置时不得外泄 api_key
