# 吉祥物模式（ip-as-logo skill 移植）

> 完成：2026-09-14（一期，无 LLM 提案；后端零改动，全部走 rawPrompt 通道）

- 来源：`docs/调研/ip-as-logo-skill 调研笔记.md`；规则已对照 [SKILL.md 原文](https://github.com/s1dashu/ip-as-logo-skill)（MIT）逐条核对
- 决策：不接对话模型（3 方向 AI 提案后期再加）；生成页加第三模式「吉祥物」，参数按 skill 规则做成默认可选项
- 关键依托：提示词在前端组装后走专家式 `rawPrompt` 原样发送通道 → **后端零改动**；天然规避引导式收尾含 "app icon" 与 skill "绝口不提 logo/图标" 的冲突

## 参数设计（默认值 = skill 默认）

| 参数 | 默认 | 说明 |
|------|------|------|
| IP 主体 | 必填 | 注入 Subject 行 `<subject>` |
| 定义特征 | 空（AI 自定） | skill 限定最多一个物种定义特征 |
| 配色 | 自动 | 自动 = AI 按主体语境定三色；自定义 = 主色①+主色②+背景色 |
| 出现角落与张数 | 左右各半 · 6 张 | 奇数张左下、偶数张右下；仅左下/仅右下 = 3 张 |
| 补充描述 | 空 | 追加一行 Additional notes |

固定不可配（skill DNA）：4–7 大基本形状、占比 85–95%、三色语义、32px 可辨、禁文字水印；Constraints 行保留在主提示词内（单一通道，不自动填充负向提示词——三家服务商对 negative_prompt 支持不一致）。
