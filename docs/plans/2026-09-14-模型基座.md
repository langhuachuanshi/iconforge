# 模型基座：可插拔模型注册表（抠图 + 智能擦除）

- 背景：①MI-GAN 实测质量不达标，用户要求删除；②模型（含抠图）应可插拔——随时导入自定义 ONNX / 删除，加模型不改代码
- 设计：
  - SQLite 新表 `custom_models(id, category, name, filename, params, created_at)`，category ∈ {remove_bg, inpaint}
  - `services/model_registry.rs` 统一注册表：内置种子（代码内，带下载 URL）+ 自定义（DB，导入文件）→ `ModelDef`
  - 参数按类别存 JSON：inpaint = io 约定（float01 / uint8）；remove_bg = 归一化 + sigmoid + 输入名
  - 删除语义：内置 → 仅删文件（条目保留可重下）；自定义 → 删文件 + 删记录（条目消失）
  - 默认模型沿用 config 键（bg_model / inpaint_model），自定义 id 同样可选为默认
