# 去水印（LaMa ONNX 本地图像修复）

- 需求：千问网页下载图的右下角"千问AI生成"半透明水印（位置固定，约 x63-95% / y88-95%）；API 直出图无可见水印（仅元数据带 TC260 AIGC 隐式标识）
- 方案（用户选定）：LaMa (Big-LAMA) ONNX 本地修复，复用现有 ort + 模型按需下载体系（hf-mirror.com/Carve/LaMa-ONNX，lama_fp32.onnx ~208MB，已验证可访问）
- 交互：编辑器新增「去水印」工具；遮罩 = 右下角预设框（百分比可调，默认 x60 y84 w40 h16），画布 overlay 实时预览；模型未下载时引导下载
- 边界说明：修复仅替换遮罩内像素；编辑器现有"手动修补"是擦除到透明，不适用此场景
